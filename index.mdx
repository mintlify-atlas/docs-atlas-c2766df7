thiserror is a Rust crate that eliminates the boilerplate of implementing `std::error::Error` by hand. Add `#[derive(Error)]` to any struct or enum, annotate variants with `#[error("...")]`, and get a complete, idiomatic `Error` implementation — including `Display`, `From`, and `source()` — with zero runtime overhead.

## How It Works

thiserror is a procedural macro crate. At compile time it reads your `#[derive(Error)]` annotation and generates the trait implementations that you would otherwise write by hand. The generated code is identical to what an experienced Rust developer would produce — no runtime cost, no magic.

<Steps>
  <Step title="Add to Cargo.toml">
    Add thiserror as a dependency in your `Cargo.toml`.

    ```toml Cargo.toml
    [dependencies]
    thiserror = "2"
    ```
  </Step>
  <Step title="Derive Error on your type">
    Annotate your enum or struct with `#[derive(Error, Debug)]` and add `#[error("...")]` messages.

    ```rust
    use thiserror::Error;

    #[derive(Error, Debug)]
    pub enum AppError {
        #[error("file not found: {path}")]
        FileNotFound { path: String },
        #[error("parse failed: {0}")]
        ParseError(#[from] std::num::ParseIntError),
        #[error("unknown error")]
        Unknown,
    }
    ```
  </Step>
  <Step title="Use your error type">
    Return your error from functions — the `From` impls generated by `#[from]` make `?` propagation seamless.

    ```rust
    fn parse_config(s: &str) -> Result<i32, AppError> {
        let n: i32 = s.trim().parse()?;  // ParseIntError auto-converts via #[from]
        Ok(n)
    }
    ```
  </Step>
</Steps>

## Key Features

<CardGroup cols={2}>
  <Card title="Zero API footprint" icon="eye-slash">
    thiserror never appears in your public API. Switching to or from it is not a breaking change.
  </Card>
  <Card title="Automatic From impls" icon="arrows-rotate">
    Mark a field with `#[from]` to generate a `From` conversion and wire up `source()` automatically.
  </Card>
  <Card title="Transparent forwarding" icon="arrow-right-arrow-left">
    Use `#[error(transparent)]` to delegate both `Display` and `source()` to an inner error.
  </Card>
  <Card title="no_std compatible" icon="microchip">
    Works in `no_std` environments — disable the default `std` feature to opt out of path formatting.
  </Card>
</CardGroup>
